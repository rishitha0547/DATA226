**Homework 8 – Pinecone Airflow Pipeline**

This homework sets up a Pinecone vector database workflow as an Airflow DAG.
The project installs sentence-transformers and pinecone, configures Pinecone credentials as Airflow Variables, downloads and processes sample text data, creates a Pinecone index, generates embeddings, ingests them, and runs a search query — all inside Airflow.
